# Patch Bags 3D models

AR Phase 1 looks for `assets/models/ivory-spiral-ar.glb`.

Upload the GLB from `PatchBags_AR_Phase1_Ready_To_Upload.zip` to this folder to enable the product's 3D/AR viewing.

The AR widget is progressive: if the model is absent, photos and shopping work normally.

The bag dimensions in the GLB are illustrative and require real measurements before representing actual size.
