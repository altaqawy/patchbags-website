# PatCh.BaGs — Handmade Studio

Photo-first editorial storefront prototype for handmade pieces from Alexandria, Egypt.

The English-language site uses the original Playfair Display, DM Sans and Manrope fonts, preserved navigation, responsive hero and marquee. The product catalogue includes 12 visual product entries and a multi-image detail gallery. Prices, colors, availability, dimensions and naming should be confirmed by the owner before checkout.

Open `index.html` locally; no build tools required. Host using GitHub Pages.
