# PatCh.BaGs — Handmade Storefront

A Framer-inspired, responsive English-language storefront concept for PatCh.BaGs in Alexandria, Egypt.

## Preview
Open `index.html` locally or deploy as a static site. The site uses `styles.css`, `script.js` and images in `assets/`.

## Features
Responsive layout, animated product collection, category filters, product detail previews, on-page search, an enquiry list, and Instagram contact links.

## Before commercial launch
Product names, prices, variants, stock and claims are placeholders to confirm with the brand owner. This is a static concept, not a payment or order processing system. Photographs were extracted from provided brand screenshots; original high-resolution source images are preferred for final launch.
